Por que Redes de Computadores?

11/02

Quando o assunto é informática, é impossível não pensar em redes de computadores. Elas estão presentes em todo lugar:

  • No banco: caixa eletrônico ligado ao computador central
  • No supermercado: caixa registradora que debita do estoque o produto
  • No pagamento: TEF que se comunica com a administradora do cartão
  • Em casa: acessando a internet

🔄 Troca de Informações

Ex: João recebe um catálogo de produtos do fornecedor X. Alfredo envia uma nota de pedido para o fornecedor X.

🖨️ Compartilhamento de Recursos

Ex: Computador A compartilha a internet. Computador B compartilha a impressora.

Hardware de Rede

24/02

O que é hardware de rede?

Refere-se a todos os dispositivos físicos utilizados para estabelecer, manter e gerenciar redes de computadores. São essenciais para a comunicação entre diferentes sistemas e para a troca de dados em uma rede.

🔁 Roteador

  • Conecta diferentes redes
  • Gerencia o tráfego de dados
  • Garante que informações cheguem ao destino correto
  • Pode oferecer firewall e NAT (Network Address Translation)

🔀 Switch

  • Fundamental para criar redes locais (LANs)
  • Opera na camada de enlace do modelo OSI
  • Recebe pacotes e encaminha ao dispositivo correto
  • Processa múltiplas transmissões simultaneamente
  • Reduz latência e aumenta largura de banda

📡 Modem

  • Permite conexão da rede local à internet
  • Converte sinais digitais ↔ analógicos
  • Facilita comunicação entre provedor e dispositivos
  • Responsável por permitir acesso à internet

📶 Access Point (Ponto de Acesso)

  • Permite conexão de dispositivos sem fio a redes com fio
  • Expande cobertura de rede sem fio
  • Permite mais dispositivos em áreas maiores

🔴 Hub (repetidor "burro")

  • Envia dados para TODOS os aparelhos conectados
  • Gera mais tráfego e colisões

🟢 Switch (inteligente)

  • Direciona dados APENAS ao dispositivo de destino
  • Reduz tráfego e colisões
💡 Dica: Um computador precisa de uma placa de rede para se conectar à internet ou qualquer rede.

Tipos de Rede

03/03

Critérios para classificar uma rede:

Abrangência Modelo de Computação Tipo de Comutação Garantia de Entrega Previsibilidade Topologia Método de Transmissão Arquitetura Protocolo
🗺️

Quanto à Abrangência

Redes classificadas de acordo com o tamanho da área geográfica que elas abrangem.

Tipo Nome Completo Abrangência Características
LAN Local Area Network Sala a um prédio Tipo mais comum; rede local
WLAN Wireless Local Area Network Igual à LAN Sem uso de cabos (wireless)
VLAN Virtual Local Area Network Qualquer distância Máquinas distantes que fazem parte de uma LAN virtual
CAN Campus Area Network Dois ou mais prédios próximos Universidades, hospitais, grandes empresas
MAN Metropolitan Area Network Até uma cidade inteira Conexão feita por concessionária de telecomunicação
WAN Wide Area Network Mais que uma cidade Rede de longa distância. A Internet é o melhor exemplo.

Quanto ao Modelo de Computação

04/03

Redes classificadas segundo a maneira como os dados são processados.

Centralizada Distribuída Cooperativa

🏛️ Rede de Computação Centralizada

  • Computador central: máquina com grande capacidade de processamento
  • Terminais: acessam o computador central para realizar o processamento
  • São "burros" (sem processador) — têm apenas dispositivos de E/S (entrada e saída)
  • Ainda muito usada em bancos e companhias aéreas

🌐 Rede de Computação Distribuída

Cada máquina da rede tem seu próprio processador. Subtipos:

Cliente-Servidor
  • Servidor: executa um ou mais serviços (e-mail, web, backup, arquivos...)
  • Cliente: solicita um serviço
  • Tem serviço de diretório — usuários se autenticam e verificam permissões
  • Administração da rede é centralizada
Ponto-a-Ponto (P2P)
  • Típica de redes domésticas ou de escritório
  • Qualquer computador pode funcionar como servidor a qualquer momento
  • Serviços específicos (ex: e-mail) devem ser fornecidos por servidor fora da rede
  • Sem serviço de diretório — rede administrada por cada usuário
Baseada em Servidor
  • Arquitetura similar à centralizada
  • Diferença: o terminal possui processador, funciona como cliente
  • Execução de processamento depende da aplicação
  • Ex: redes com Telnet e SSH
Front-End / Back-End
  • Servidor front-end se comunica com servidor back-end
  • Ex: servidor web (front-end) + servidor de banco de dados (back-end)
  • O BD armazena os dados; o web busca os dados e monta a página para o cliente

🤝 Rede de Computação Cooperativa

Vários computadores da rede são usados para realizar uma parte do processamento.

  • Computação em nuvem: ocorre em computadores "comuns" conectados à internet
  • Computação em grade: ocorre em servidores dedicados
🔀

Quanto ao Tipo de Comutação

17/03

Comutação é o processo de interligar dois ou mais pontos entre si.

🔴 Comutação de Circuito

  • Uma conexão é montada como se fosse um fio ligando os computadores
  • Dados trocados livremente nos dois sentidos
  • Sempre usa o mesmo caminho (circuito)
  • Dados sempre recebidos na ordem de envio

🟢 Comutação de Pacotes

  • Dados divididos em pacotes
  • Caminho de cada pacote não é fixo
  • Roteadores definem o melhor caminho (curto ou menos congestionado)
  • Pacotes podem chegar fora de ordem no destino
  • Usada por diversas arquiteturas de rede atuais
📦

Quanto à Garantia de Entrega de Dados

✅ Orientada a Conexão

Garante a entrega de dados. Etapas:

  1. Transmissor envia pedido
  2. Receptor envia OK e a conexão é estabelecida
  3. Transmissor envia os pacotes de dados
  4. A cada pacote recebido, receptor envia confirmação ao transmissor
  5. Quando termina, transmissor encerra a conexão

❌ Não Orientada a Conexão

  • Não garante a entrega de dados
  • O transmissor envia os pacotes
  • O transmissor não sabe de fato se os dados chegaram ao destino
⏱️

Quanto à Previsibilidade de Funcionamento

🟢 Rede Determinística

  • Entrega os pacotes de dados num intervalo de tempo previsível

🔮 Rede Probabilística

  • Não se sabe antecipadamente quando o pacote chegará ao destino
  • Também chamada de rede estatística ou aleatória

Flashcards Rápidos

O que é internet?
Rede mundial de computadores conectados que trocam informações usando protocolos. Melhor exemplo de WAN.
Internet vs Intranet
Internet: rede global e pública. Intranet: rede privada de organizações, restrita a membros autorizados.
O que é IP?
Número único atribuído a cada dispositivo em uma rede. Funciona como identificador para comunicação entre dispositivos.
Como funcionam os pacotes?
Dados divididos em partes menores. Cada pacote tem endereço de destino e origem. Viajam por caminhos diferentes e são reunidos no destino.
Download vs Upload
Download: receber dados. Upload: enviar dados.
O que é Wi-Fi?
Tecnologia que permite conexão sem fio usando ondas de rádio.
Função do roteador em casa
Distribui a internet para vários dispositivos e cria a rede dentro de casa.
Hub vs Switch
Hub: envia dados para todos (burro). Switch: envia só para o destino correto (inteligente).
Computadores em rede significa...
Estão interligados de forma que podem se comunicar e trocar informações.
Rede mais comum?
LAN (Local Area Network) — rede local, usada em casas, escritórios e escolas.
